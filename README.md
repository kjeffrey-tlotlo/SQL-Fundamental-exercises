# SQL Fundamental Exercises

This repository contains SQL practice exercises designed to build and strengthen foundational SQL skills. The exercises cover essential database concepts and querying techniques commonly used in data analysis, reporting, and database management.

## Topics Covered

- SELECT statements
- Filtering data with WHERE
- Sorting results with ORDER BY
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING clauses
- JOIN operations
- Subqueries
- String and date functions
- Data manipulation (INSERT, UPDATE, DELETE)
